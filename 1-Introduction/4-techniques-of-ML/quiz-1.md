
# **Machine Learning Techniques Quiz**

### **Multiple Choice Questions (MCQs)**

1.  **What is the main goal of supervised learning in machine learning?**
    
    -   A) To generate new data points
    -   B) To classify or predict based on labeled data
    -   C) To find hidden patterns in data without labels
    -   D) To optimize hyperparameters automatically
2.  **Which of the following is an example of supervised learning?**
    
    -   A) Clustering customers based on purchasing behavior
    -   B) Predicting the price of a house from its features like size, location, etc.
    -   C) Grouping animals based on common characteristics
    -   D) Detecting anomalies in network traffic
3.  **Which technique is used in unsupervised learning to group similar data points?**
    
    -   A) Linear regression
    -   B) K-means clustering
    -   C) Decision trees
    -   D) Support vector machines
4.  **Which of these is NOT typically associated with supervised learning?**
    
    -   A) Regression
    -   B) Classification
    -   C) Clustering
    -   D) Both A and B
5.  **In reinforcement learning, an agent learns by:**
    
    -   A) Following a predefined set of rules
    -   B) Receiving feedback from the environment in the form of rewards or penalties
    -   C) Identifying patterns from labeled data
    -   D) Solving puzzles and problems step-by-step
6.  **What is the primary difference between classification and regression?**
    
    -   A) Classification is used for numerical outcomes, while regression is used for categorical outcomes
    -   B) Classification is used for categorical outcomes, while regression is used for numerical outcomes
    -   C) Regression does not use training data, while classification does
    -   D) Classification uses unsupervised learning, while regression uses supervised learning
7.  **Which of the following is a characteristic of unsupervised learning?**
    
    -   A) Requires labeled data
    -   B) The algorithm finds patterns without prior knowledge of the output
    -   C) The model makes predictions based on past outcomes
    -   D) It only works with numerical data
8.  **What is the primary purpose of a loss function in machine learning?**
    
    -   A) To split the data into training and testing sets
    -   B) To measure how well the model’s predictions align with the actual results
    -   C) To increase the complexity of the model
    -   D) To visualize the distribution of the data
9.  **Which machine learning technique is most appropriate for predicting customer churn based on historical data?**
    
    -   A) Clustering
    -   B) Classification
    -   C) Reinforcement learning
    -   D) Regression
10.  **What does the term "overfitting" refer to in the context of machine learning?**
    
    -   A) When a model performs well on unseen data but poorly on training data
    -   B) When a model is too simple and cannot capture the patterns in the data
    -   C) When a model is too complex and fits noise in the training data
    -   D) When a model does not learn from the data at all
